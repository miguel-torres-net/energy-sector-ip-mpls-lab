# Energy Sector IP/MPLS Lab

(Work in progress, this repo will be updated very frequently)

The goal of this project is to show the end-to-end architecture of large scale critical infrastructure communications (particularly, electric substations and eventually oil/gas pipelines) through a dedicated IP carrier. This carrier will also be used by other non-OT customers.

Some of the technologies this project will use are:
* IS-IS
* eBGP/iBGP and MP-BGP VPNv4 with route reflectors
* MPLS/LDP (eventually evolving to SR-MPLS, but not in the short term)
* L3VPN (possibly L2VPN later)
* VRFs
* Linux (Debian-based FRR routers and Linux hosts)
* Python automation (starting with PyEZ for Junos. Its automatability is the main reason I chose this vendor)
* IEC-104 client/master OT traffic (communication between electrical susbtations and a control center)
    * Currently working on making a separate project for this
* tcpdump to analyze said OT traffic
* NMS/Monitoring (Observium)

I'll use at least two different router OSes:
* vJunos-router
* Linux routing (Debian 12 with FRRouting)

I'll include both manual configs and Python scripts, as well as pcaps, screenshots and other proof of work.

The VM images are automatically generated by another project I'm working on https://github.com/miguel-torres-net/node-image-factory.

As a note, I'm using systemd ipsec0-gwX.service to persist changes like:

[Unit]
Description=Create ipsec0 and route remote LAN on GWX
After=network-online.target
Wants=network-online.target
Before=strongswan.service strongswan-starter.service charon-systemd.service

[Service]
Type=oneshot
RemainAfterExit=yes
ExecStart=-/usr/sbin/ip link add ipsec0 type xfrm if_id 1
ExecStart=/usr/sbin/ip link set ipsec0 up
ExecStart=/usr/sbin/ip route replace 172.16.X.0/24 dev ipsec0 src 172.16.X.1

[Install]
WantedBy=multi-user.target
